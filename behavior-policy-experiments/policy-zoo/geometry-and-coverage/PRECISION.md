# What is matched exactly?

The common reset observations and the regularizer index stream are bit-for-bit identical across policy/source conditions within a seed. Consequently their observed starting-state histograms and regularizer input multisets match exactly.

The common pool is generated by jittered stratification in log-distance using float32 tensors. Converting a sample through exp/log and the inverse-distance renderer can move a boundary-near point into an adjacent analysis bin. Thus “uniformly stratified” describes the construction, not a guarantee of exactly 512 reconstructed samples in each of the 32 log bins. Source manifests report the actual histograms. A preflight check found a one-sample boundary difference in seed 13; no sampler or experimental condition was changed.

This has no effect on cross-policy matching: every condition receives the same actual observations. Tests check exact pool equality and physical transitions, and allow the small rounding error relative to an ideal uniform histogram. Successor histograms and stationarity are not claimed to match.
