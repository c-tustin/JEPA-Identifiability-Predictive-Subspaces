This repository holds all the code explorations in my project under Richard Hakim at the Kempner Institute. We are studying identifiability and predictive utility in JEPA models, using mechanistic interpetability methods and mathematical concepts like quiver representations, barycentric subdivisions, and homology. 

The main branch will include writeups, research process notes, practice code, and main results. Other branches include shorter experiments, like paper replications and toy models. These experiments are meant to give a foundation for further inquiry.
