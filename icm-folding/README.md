# ICM policy folding: progress and repairs

Consolidated research workspace, updated November 19, 2026. This brings the existing folding, policy, mechanism, and repair work together at the main workspace level. Start with [the merged progress report](PROGRESS.md).

Several named folders here are relative symbolic links to the original studies; newer experiment directories are authored directly here. They expose the existing code, checkpoints, figures, protocols, and results without duplicating large artifacts or changing paths used by running experiments. The originals remain the source of truth. Open the source-document links below for documentation with its original relative links intact. Run reproduction commands from the main `kempner` directory using the original paths in each protocol.

For the strongest current causal evidence, start with [what causes folding in these saved runs](loss-source-crossing/README.md). It separates SIGReg occupancy from temporal alignment and tests actual optimizer-history interventions.

Representation plots label physical distance separately from learned code units; see [how to read the InfoNCE distance representations](raw-embedding-infonce/README.md#reading-the-distance-representation-graphs).

Latest raw/own-code InfoNCE only: [all distance representations](raw-embedding-infonce/output/latest_distance_representations.png), [distance and slope](raw-embedding-infonce/output/latest_seed131_distance.png), [learning snapshots](raw-embedding-infonce/output/latest_distance_learning.png), and [what a no-fold guarantee would require](raw-embedding-infonce/README.md#can-infonce-guarantee-no-folding).
