# Raw observation–own embedding InfoNCE

Fixed November 18, 2026 before running this experiment.

This is a new training objective, not a relabeling of the earlier temporal InfoNCE results. Positive pairs are `(x_i, f(x_i))`; negatives are `(x_j, f(x_i))` for other endpoint observations. No successor-prediction or temporal alignment loss is used. Both current and successor observations supply objects, but their transition correspondence is not a positive-pair definition.

Reuse the unchanged scalar encoder (6→48→48→1 tanh MLP, input tanh(4x)), historical source seeds 130–139 and the already collected follow-up sources 140–144. All fits start from scratch with the same encoder initialization, 80/20 episode split, batch plan, Adam 0.001, 4,000 updates and half-constant/half-cosine schedule as the original alternative-objective study. The follow-up sources are reused data, not a new prospective validation cohort. No physical coordinates, ordering labels or actions enter this loss.

For each batch of 512 transitions, use its first 128 current and first 128 successor observations: 256 objects and 255 negatives per code. This changes candidate count and compute from the earlier temporal run's 128; it is not a matched-compute causal comparison. Standardize raw sensor coordinates by training-endpoint means and population standard deviations (floor 1e-6), without passing this branch through an encoder or tanh. These are fixed statistics fitted only on training episodes.

The explicit compatibility critic is `s(x,z) = -mean_k((standardize(x)_k - g(z)_k)^2)/(2*0.1)`, with a learned 1→48→48→6 tanh MLP `g`. This is a restricted quadratic observation/code critic, not a general joint neural density-ratio estimator. Optimize cross-entropy over candidate raw observations for each code; diagonal object identities are positives. Train encoder and critic jointly. No separate reconstruction MSE, SIGReg, VICReg, EMA, code normalization, collision mining, projector on the raw branch or tuning sweep is added. The critic is discarded for encoder evaluation. Fixed raw scaling sets the score units; the scalar latent's scale is unconstrained.

Duplicate/near-identical observations remain negatives, including stay transitions and repeated sampled rows; candidate-index accuracy is therefore not perfect-identifiability evidence. The loss may preserve nuisance information in more complex observations. On this deterministic renderer, preserving distinguishability is relevant to folding, but InfoNCE with finite negatives and this critic supplies no injectivity guarantee.
